# Robot Monitoring Interface

六轴机器人监控控制台。页面按工业监控台的深色版面组织：连接与运行状态、关节角度、当前任务和执行记录放在同一块工位窗口里，曲线用 ECharts 实时绘制。

数据来自浏览器内的模拟循环（托盘 A3 → 工位 B2），不连接真实控制器。

## 运行

```bash
npm install
npm run dev
```

开发服务器默认在 [http://127.0.0.1:47321](http://127.0.0.1:47321)。

```bash
npm run build
npm run preview
```

## 技术

- Vue 3 + TypeScript + Vite
- ECharts 绘制关节角度与转速
- 模拟数据：关节插值、任务阶段、告警与执行记录

## 可以点的地方

- 左上角「已连接 / 执行中」切换链路和任务
- 关节行或曲线图上的 J1–J6 切换高亮轴
- 相机按钮：电源、暂停、抓拍、网格
- 执行记录可只看错误，并确认告警
